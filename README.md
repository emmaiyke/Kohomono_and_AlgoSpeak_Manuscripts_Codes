Kohomono and AlgoSpeak Manuscripts & Codes

This repository contains datasets, scripts, figures, 
and manuscript resources for two computational linguistics projects. 
The first project investigates the phonological structure of Kohomono, 
an endangered Upper Cross language of Nigeria, using field-derived linguistic data, 
acoustic analysis, and interpretable machine-learning approaches. 
The second project investigates algospeak and culturally embedded digital discourse 
through machine-learning and sociolinguistic methods to examine language adaptation, 
coded communication, and AI-mediated digital interactions.
