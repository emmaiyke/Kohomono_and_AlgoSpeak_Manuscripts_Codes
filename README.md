This repository contains the dataset and analysis code used in the study A Corpus-Based 
Computational Analysis of Kohomono Phonological Structure. The dataset consists of a phonemically
transcribed Kohomono lexical corpus containing 962 entries (955 analyzable items) collected from
21 speakers across seven Bahomono communities in Abi Local Government Area, Cross River State, 
Nigeria. The code includes scripts for corpus preprocessing, segment extraction, tone and syllable 
analysis, C/V skeleton generation, descriptive statistics, principal component analysis (PCA),
k-means clustering, hierarchical clustering, and Random Forest classification. 
All scripts were developed in Python using pandas, NumPy, scikit-learn, and Matplotlib.
